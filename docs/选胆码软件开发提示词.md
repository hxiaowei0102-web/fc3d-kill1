# 福彩3D 选5胆码软件 · 开发提示词（可直接交给 AI 执行）

> 用途：让 AI 从零开发一个「福彩3D 每日预测5个胆码」的软件，采用与现有「百十个杀一码」项目完全相同的算法框架与交付模式（本地网页 + 云端全自动）。
> 参考项目（算法/页面/部署模板）：D:\百十个杀一码（杀一码版）、D:\新版百十个（杀两码版，页面风格基准）。

---

## 一、项目目标

每天预测下期福彩3D开奖的 **5 个胆码**（0-9 中选 5 个数字），命中判定：**下期开奖的百/十/个 3 个数字中，至少有 1 个出现在 5 胆内**即算命中（以下简称「5胆命中」）。

- 随机基线：5 胆命中 = 1 − C(5,3)/C(10,3) = **91.67%**
- 单码胆中基线：某个具体数字出现在开奖 3 码中 = 1 − (9/10)³ = **27.1%**
- ⚠️ 数学现实：5 胆命中基线已高达 91.67%，可提升空间有限；预测目标是把样本外命中率稳定做到 ≥ 基线，并如实向用户坦白过拟合风险，不夸大。

## 二、数据

- 源数据：`D:\福彩3D资料\fc3d-history.csv`（列：issue,hundreds,tens,ones，无日期列；当前约 8736 期，最新期 2026228）
- 复制到项目 `data/fc3d-history.csv`，云端每晚自动追加新期（多源抓取）
- 预测规则：第 i 期预测只用第 i-1 期（上期）与第 i-2 期（前2期）数据，**严禁偷看未来**

## 三、核心算法（移植自杀一码，核心差异在命中定义）

### 1. 特征引擎（59 个特征，直接复用杀一码版 `formulas.py`）
- 上期单期 34 个：b/s/g、b2/s2/g2、b3/s3/g3、和值S、和尾S10、跨度P、大中小mx/mn/md、三差值d1/d2/d3、两两积尾bs/bg/sg、三码积尾bsg、S²尾、P²尾、sum2/3/4、幂bp/gp/sp、奇偶bo/so/go/So
- 单期派生 9 个：d12/d13/d23（跨度乘积尾）、mxmn/mxmd/mnmd、S3、dsum、bsg2
- 跨期 16 个（前2期 bL/sL/gL）：bL/sL/gL、SL/S10L/PL、db/ds/dg、dS、bh/sh/gh、bpr/spr/gpr

### 2. 公式池（905 万条，与杀一码完全一致）
```
公式 = ( c1×特征A + c2×特征B [+ c3×特征C] + 常数 ) mod 10 → 输出 0-9 一个数字
单特征：系数 (1,2,3,5) × 常数 0-9
双特征：C(59,2) × 系数² × 常数
三特征：C(59,3) × 系数(1,2,3)³ × 常数
总规格 ≈ 9,053,550 条；numpy 向量化评估约 140 秒/轮
```
- 实现方式：流式生成器（不存池、内存 O(1)），`F[:, cols] * coeffs` 向量化算 200 期输出

### 3. 胆码评估（与杀一码的差异点）
- **单公式胆码命中**：公式输出数字 v，命中 = v ∈ 当期开奖3码（v 出现在 hh[i]/tt[i]/oo[i] 任一）
- **5胆组命中**：选出的 5 条公式（输出去重为 5 个不同数字 S），命中 = 开奖3码 ∩ S ≠ ∅
- 统计窗口：最新 200 期（后续可按需对比 250/350 期）

### 4. 选胆策略（按优先级）
1. **Top 公式单码榜**：905万公式逐条算 200 期单码胆中命中率，取 Top-50 公式
2. **按数字归并**：Top-50 公式按输出数字分组，每组保留命中率最高者 → 得到候选数字及其最优公式
3. **5 胆组合搜索**：
   - 方案A（推荐·贪心）：候选数字按「最优公式单码命中率」降序，依次取 5 个不同数字；若候选不足 5 个，用 Top 榜剩余公式按序补足
   - 方案B（穷举·更严）：取 Top-30 公式（输出去重后 ≥6 个数字时），穷举 C(30,5) 组合，每组算 200 期 5胆组命中率，取最高；并列裁决：组命中率 → 单码命中率之和 → 胆码字典序
4. 输出：5 个胆码（升序排列展示）+ 每条胆码对应的公式 + 单码命中率

### 5. 回测
- 固定 5 胆组，回看过去 200 期：逐期用上期/前2期算 5 条公式输出 → 5 胆组 → 对比当期开奖 3 码 → 标记命中
- 汇总：5胆命中率、逐期记录（期号/开奖/5胆/命中✓✗）、最大连错
- 回测表排序：**近期 → 远期**（最新在顶部）
- ⚠️ 回测区间与选公式区间重叠，属历史拟合，页面必须如实标注「样本外会回落」

## 四、网页要求（移动端 480px，纯静态单文件，无外部库）

参考 `D:\新版百十个\index.html` 风格：
- 紫色渐变 header（#5b3cc4 → #7b5fe0）、灰底 #f0f2f5、白卡片圆角阴影

- 统计区：5胆命中率（近200）、单码胆中率×5、随机基线对比、最大连错、穷举公式数
- 200 期回测表：期号 | 开奖 | 5胆 | 命中（✓/✗，行左绿/红边框），近期→远期
- 公式说明卡：每个胆码对应的公式 + 白话解释 + 单码命中率

- 数据以 `const P = {...}` 内嵌 JSON

## 五、云端全自动部署（沿用杀一码模式）

- 新仓库（**不得覆盖**现有 fc3d-kill1）：如 `hxiaowei0102-web/fc3d-danma5`（或老板指定名），GitHub Pages 子路径部署
- GitHub Actions workflow：三重 cron（UTC 0 14 / 30 15 / 0 17 = 北京 22:00/23:30/01:00），21:30 开奖后执行，3 次机会兜底，concurrency 防撞车
- 多源降级抓取（huiniao / 17500 / apihz / cwl / 55128 / 8200，urllib 无第三方依赖），新期号自动**追加** CSV（不覆盖历史，只收 > 本地最新期号的数据防倒灌）
- 全自动闭环：抓数据 → 追加 CSV → 穷举选 5 胆 → 200 期回测 → 生成 static/index.html → 提交 + 部署 Pages
- 幂等：数据与 5 胆组均无变化时不重写页面（含时间戳），workflow 以 CSV/公式文件/页面三方 git diff 判断，无变化跳过提交与部署
- 依赖：`pip install "numpy>=1.26,<3"`（锁版本）
- 页面 `updated` 用北京时间

## 六、风险与诚实声明（必须写入页面与代码注释）

- 905万公式在 200 期上穷举选最优 = **过拟合**：窗口内命中率必然高于样本外真实水平
- 参考已验证数据（杀一码同框架样本外测算）：窗口内 99% 的公式样本外 3 杀全中仅 ~72.7% ≈ 随机基线 72.9%；胆码同理，样本外大概率回落到基线 91.67% 附近
- 页面 footer 与 README 必须注明「仅供研究参考 · 不构成投注建议 · 历史拟合样本外会回落」
